01 / ROUTING

LLM Gateway

—

Keys resolve from A3THER_*_API_KEY env (or .env), then config/api_keys.json. On 429/5xx the router falls back natively.

02 / EXTENSIONS

Plugins

Drop a folder with an a3ther-plugin.json into plugins/ — Python or JavaScript — and it hot-loads on the next scan.

03 / MCP HOST

MCP Servers

—

Configured in config/mcp-servers.json (stdio or HTTP JSON-RPC 2.0). Toggles persist in config/mcp_state.json.

04 / CATALOG

MCP Server Catalog

One-click install — npx/uv/go servers are written to mcp-servers.json and connected; git servers are cloned + built automatically. Community tabs pull live from the awesome lists and the official registry.

05 / TOOLS

Connected MCP Tools

—

Tools are addressed as server__tool and are also available to the AI brain's tool pipeline.

06 / REMOTE DEV

SSH Servers

—

Profiles live in config/servers.json or A3THER_SSH_* env. Trigger sessions with “a3ther, act as a dev on <server>”.

07 / SELF-HEALING

Freaky-Fix Autopilot

Run a command to start the loop — failures are diagnosed, patched by the strongest LLM, and re-run up to 3 times.
